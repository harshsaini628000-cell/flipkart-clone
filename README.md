# Flipkart Clone

A responsive front-end clone of the Flipkart e-commerce web platform. This project recreates the signature Flipkart user experience, featuring the primary search navigation, top category navigation bar, promotional banner carousel, and product showcase deal cards.

---

## Live Demo & Repository

* **Repository:** [harshsaini628000-cell/flipkart-clone](https://github.com/harshsaini628000-cell/flipkart-clone.git)
* **Live Demo (GitHub Pages):** `https://harshsaini628000-cell.github.io/flipkart-clone/` *(if Pages is enabled)*

---

## Features

* **Flipkart Header Navigation**: Signature blue header featuring the Flipkart logo, search bar with search icon, "Become a Seller" button, and user login/cart links.
* **Top Category Bar**: Visual category navigation showcasing items like Grocery, Mobiles, Fashion, Electronics, Home & Furniture, Appliances, and Travel.
* **Hero Banner Slider**: Promotional banner carousel displaying seasonal discounts, top offers, and new launches.
* **Deal Cards & Product Grids**: Sections showcasing "Best of Electronics", "Beauty, Food, Toys & More", and deals of the day with prices, discounts, and quick links.
* **Multi-Column Footer**: Detailed footer layout including customer care links, company info, social handles, mail address, and registered office details.
* **Responsive Layout**: Fluid design adapting cleanly across desktop, tablet, and mobile device screens.
